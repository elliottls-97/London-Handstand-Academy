WHERE IT GOES
-------------

    your-repo/
      index.html                     (leave alone)
      handstand-ladder-app.html      <- replace with the one here
      manifest.json                  <- new
      sw.js                          <- new
      icons/                         <- new folder, keep this name
        apple-touch-icon.png
        icon-192.png
        icon-512.png
        icon-512-maskable.png

The icons folder must keep its name and stay at the top level. The app
looks for "/icons/icon-192.png" and "/manifest.json" as absolute paths,
so if they end up nested deeper they will 404.

FOR FUTURE UPDATES
------------------
Whenever you change handstand-ladder-app.html from now on, also bump the
version string near the top of sw.js:

    const CACHE_VERSION = 'lha-v1';   ->   'lha-v2', 'lha-v3', ...

If you don't, returning visitors keep getting the old cached copy and
your changes appear not to have worked. This caught me out during the
build: I made changes, retested, and saw no difference at all because
the browser was serving a cached version.
